# Icon source

No icon is shipped for this repository.

The homarr-labs/dashboard-icons collection (`svg/sinusbot.svg`, `png/sinusbot.png`) was
evaluated. The SVG file embeds a third-party copyright notice in its `<desc>` element, and
the origin of the artwork could not be verified as the official SinusBot logo. The icon was
therefore not used. The selfh.st/icons collection has no SinusBot entry.

If an official, verified logo becomes available from the upstream project, add it here as
`icon.svg` together with a source entry in this file.
